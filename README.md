# Inteligência Comercial

**Em planejamento · SQL e Power BI**

Onde as vendas e a margem bruta variaram, e quais produtos e canais explicam a mudança? O projeto usará dados sintéticos de uma empresa fictícia para investigar essa pergunta.

## Primeira versão

1. Modelar vendas, produtos, clientes, canais e calendário, com dicionário de dados.
2. Documentar regras de receita líquida, descontos, devoluções e margem bruta. Implementar consultas SQL reproduzíveis.
3. Construir um painel no Power BI para comparar períodos e detalhar resultados por produto e canal.
4. Apresentar três conclusões sustentadas pelos dados, com as limitações da análise.

**Critério de entrega:** conferir os totais de receita e margem entre SQL e Power BI sob os mesmos filtros e publicar instruções para reproduzir a análise.

**Próximo passo:** definir a granularidade de cada venda e fechar as regras dos indicadores antes de gerar a base.
